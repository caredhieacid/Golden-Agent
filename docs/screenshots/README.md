# Screenshots and Media Guide

Use this folder for public-facing README assets.

Recommended files:

- `cover.png` (recommended 1600x900)
- `demo-user.gif` (10-20s, under 12MB)
- `demo-ai.gif` (10-20s, under 12MB)
- `demo-admin.gif` (10-20s, under 12MB)

Tips:

- Keep UI text clear at GitHub width.
- Use a darkened background behind bright charts.
- Prefer short, focused GIF loops over long recordings.
- Remove sensitive account data before export.
